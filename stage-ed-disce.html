Stages / Ed&Disce · 2025/2026

Développeur Web Stagiaire — Ed&Disce

Participation au développement d’une application web orientée formation : travail principal sur le back-end, l’API REST, la sécurisation des accès et l’intégration de fonctionnalités intelligentes (chatbot, traitement de contenu).

Contexte

Lors de mon stage de deuxième année (SN2) chez Ed&Disce, j’ai contribué à une stack moderne : API FastAPI, base MongoDB, conteneurisation Docker et tests automatisés. Cette expérience m’a permis de renforcer mes compétences en développement web full-stack, en bases NoSQL, en conception d’API et en intégration de services d’intelligence artificielle.

Missions réalisées

  • Authentification et gestion des utilisateurs — mise en place des mécanismes d’inscription, de connexion et de gestion des sessions (tokens JWT, validation des requêtes via une dépendance de sécurité FastAPI).
  • API REST avec MongoDB — conception et implémentation des opérations CRUD sur les ressources métier (cours, sections), avec modèles Pydantic et persistance dans MongoDB.
  • Intégration d’un chatbot / IA — connexion de fonctionnalités intelligentes à l’application pour améliorer l’interaction utilisateur (assistant conversationnel, modèles Mistral / ChatGPT selon les besoins du projet).
  • Tests et validation — vérification du bon fonctionnement des endpoints, tests de sécurité et correction des anomalies (suite pytest).
  • Conteneurisation — déploiement local reproductible de l’API et de MongoDB via docker compose.

Technologies mobilisées

Python 3.12+
FastAPI API REST, Swagger / ReDoc
MongoDB
Docker · Compose
JWT Authentification (python-jose)
Pydantic Schémas et validation
pytest Tests unitaires et sécurité
IA Transformers · extraction de mots-clés

Points techniques (extrait du codebase)

  • routers/courses.py et routers/sections.py — endpoints CRUD protégés, filtrage par propriétaire (owner).
  • core/security/ — gestion des clés API, tokens JWT, dépendance SecurityDependency sur chaque requête sensible.
  • ai/keywords.py — module IA (modèle Flan-T5) pour extraire des mots-clés à partir du contenu des sections.
  • docker-compose.yml — services API + MongoDB, healthchecks, variables d’environnement.
  • Documentation interactive auto-générée : /docs (Swagger UI).

Compétences acquises

API REST · MongoDB · Authentification · CRUD · Développement back-end · Intégration chatbot / IA · Gestion de base NoSQL · Tests et débogage · Docker.
