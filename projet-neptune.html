Hôtel Neptune

Application web de réservation en ligne pour un hôtel fictif : consultation des chambres, réservation, espace client et interface d’administration.

Présentation

Projet scolaire développé en PHP avec une base MySQL. Le site permet aux visiteurs de parcourir les chambres, de réserver un séjour et de gérer leur compte ; les administrateurs disposent d’un back-office pour l’inventaire, les réservations et la gestion des données.

L’architecture sépare clairement la partie publique (public/), la logique métier (includes/) et l’administration (admin/), avec un accès aux données centralisé via des DAO dans includes/db/.

Technologies utilisées

PHP 8+
MySQL / MariaDB
HTML / CSS
JavaScript
Composer Gestion des dépendances PHP
PDO Accès sécurisé à la base (pdo_mysql)

Fonctionnalités principales

  • Pages publiques : accueil, présentation des chambres et équipements
  • Parcours de réservation et gestion du compte client
  • Interface d’administration (chambres, réservations, données)
  • Scripts SQL d’initialisation et de migration de la base
  • Lancement en local via serveur PHP intégré (php -S localhost:8000)

Structure du dépôt

  • public/ — pages et assets accessibles au navigateur
  • includes/ — pages applicatives (chambres, réservation, compte)
  • admin/ — back-office administrateur
  • includes/db/ — couche d’accès aux données (DAO)
